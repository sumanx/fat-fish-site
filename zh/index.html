DeepSeek Harness（DSH）的原生移动客户端。

这个 App 是什么

肥鱼把你的手机连接到你自己运行（或他人为你运行）的 DeepSeek Harness Host。它只是客户端：不提供 AI 服务、没有账号体系、也没有演示内容或隐藏内容。没有配置 Host 时，App 打开是空态，入口是「添加服务」。

使用条件

  • iOS 15 及以上。
  • 一个可访问的 DeepSeek Harness Host：通过 HTTPS 暴露、可经 SSH 访问，或部署在反向代理/中转之后。
  • Host 的地址与连接令牌（走 SSH 时可由 App 从 DSH 启动日志里查找）。

开始使用

1. 添加服务

打开左侧栏，点「添加服务」，选择连接方式：

  • 直连：Host 的 HTTPS 地址 + 连接令牌。自签名证书必须由你核对 SHA-256 指纹后才会信任。
  • SSH：主机、端口、用户名，以及密码或私钥。App 通过 SSH 登录，从该实例的启动日志查找连接令牌（或使用你填写的），并把请求隧道到该机器的 127.0.0.1。
  • 中转：部署在反向代理之后的 DSH 服务地址。

2. 选择会话

会话、工作区与文件都来自 Host；本机只保存草稿与导航状态。

3. 聊天

发送消息、回答提问、审批工具调用、跟进后台任务。只有在 Host 连接与本机草稿存储都就绪后，输入框才会激活。

常见问题

需要账号吗？

不需要。没有注册、登录或订阅，你直接连接自己的 Host。

输入框一直是灰的 / 显示「准备中」？

表示连接或本机草稿存储还没就绪。若持续如此，请核对地址与令牌，然后从左侧栏重新连接。

凭证存在哪里？

只存在本机 App 私有存储里，不会上传到别处；删除服务会一并移除其凭证。

为什么要我核对指纹？

因为该证书或 SSH 主机密钥不是公共机构签发的。在你通过独立渠道确认指纹之前，App 不会连接；若之后指纹变化，会再次拒绝。

自签名证书被拒绝怎么办？

改用 SSH 连接方式，或换成受信任机构签发的证书。肥鱼不会静默接受任何证书。

会把数据发到别处吗？

不会。没有分析 SDK、没有崩溃上报、没有广告。详见隐私政策。

支持深浅色和中文吗？

支持。界面跟随系统外观，并按系统语言在中英文之间切换。

仍未解决？

请开一个 issue，并附上 App 版本、iOS 版本、连接方式，以及完整错误文案（App 里有可复制的脱敏连接诊断）：
