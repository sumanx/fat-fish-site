Fat Fish

A native mobile client for DeepSeek Harness (DSH).

What this app is

Fat Fish connects your phone to a DeepSeek Harness Host that you run yourself (or that someone runs for you). It is a client only: it provides no AI service, has no account system, and contains no demo or hidden content. Without a Host, the app opens to an empty state with an “Add a Host” entry.

Requirements

  • iOS 15 or later.
  • A reachable DeepSeek Harness Host. Either exposed over HTTPS, reachable through SSH, or published behind a reverse proxy / relay.
  • The Host address and its access token (the app can find the token from the DSH startup log when connecting over SSH).

Getting started

1. Add a Host

Open the sidebar, tap Add a Host, then choose a connection type:

  • Direct — the HTTPS address of the Host plus its access token. A self-signed certificate is accepted only after you verify its SHA-256 fingerprint.
  • SSH — host, port, username, and either a password or a private key. The app logs in over SSH, looks up the access token in the DSH startup log (or uses the one you enter), and tunnels requests to 127.0.0.1 on that machine.
  • Relay — the address of a DSH server published behind a reverse proxy.

2. Pick a session

Sessions, workspaces, and files all come from the Host. Nothing is stored locally except drafts and navigation state.

3. Chat

Send messages, answer questions, approve tool calls, and follow background tasks. The composer only becomes active once the Host connection and local draft storage are both ready.

Frequently asked

Do I need an account?

No. Fat Fish has no sign-up, no login, and no subscription. You connect directly to your own Host.

Why is the composer greyed out / showing “Preparing”?

The app is still finishing the connection or the local draft store. If it stays that way, check that the Host address and token are correct, then reconnect from the sidebar.

Where are my credentials stored?

In the app’s private storage on this device only. They are never uploaded anywhere else, and deleting a Host removes its saved credentials.

Why did the app ask me to verify a fingerprint?

Because the certificate or SSH host key is not signed by a public authority. The app refuses to connect until you confirm the fingerprint out of band. If the fingerprint changes later, the connection is rejected again.

A self-signed certificate is rejected. What now?

Use the SSH connection type instead, or install a certificate signed by a trusted authority. Fat Fish never silently accepts every certificate.

Does the app send data anywhere else?

No. It has no analytics SDK, no crash reporting SDK, and no advertising. See the privacy policy.

Can I use it with light and dark themes?

Yes — the app follows your system appearance and switches between English and Chinese based on your system language.
